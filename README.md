# Instalación obligatoria de Node.js
https://nodejs.org/es/download

## Node.js
* Para hacer la instalación colocamos el comando *npm install*
- De Framework colocamos React
- Como "variant" ponemos JavaScript
- Finalmente en "linter" elegimos ESLint
Una vez hecho se creará una plantilla de TaskCampus en la carpeta actual de la terminal

* Para volver a arrancar la página nos dirigimos a la carpeta en cuestión y ponemos *npm run dev*
