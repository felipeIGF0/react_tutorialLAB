Desarrollo de Aplicaciones Web - Laboratorio React con JavaScript
Instrucciones del examen
Propósito

Completar TaskCampus a partir del proyecto base proporcionado, transformando su interfaz estática en una aplicación React para gestionar tareas académicas, el trabajo integra los contenidos de los tutoriales y una investigación acotada sobre navegación y actualización del estado.

Resultados de aprendizaje

Construir interfaces mediante componentes React y JSX.
Comunicar datos y acciones mediante props.
Gestionar estado y actualizar objetos y listas sin mutaciones directas.
Implementar listas dinámicas, filtros y renderizado condicional.
Desarrollar formularios controlados con validación.
Integrar operaciones HTTP mediante fetch, hooks y servicios.
Mantener información coherente entre distintas vistas.
Organizar y documentar un proyecto reproducible desde un repositorio público.
